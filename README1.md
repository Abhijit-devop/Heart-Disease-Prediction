# Heart Disease Prediction using Machine Learning

## Project Overview

This project predicts the likelihood of heart disease using machine learning algorithms.

## Dataset

Heart Disease Dataset from Kaggle.

## Machine Learning Models Used

* Logistic Regression
* Decision Tree
* Random Forest

## Features

* Data preprocessing
* Data visualization
* Model training and testing
* Confusion Matrix
* ROC Curve
* Feature Importance Analysis

## Results

Random Forest achieved the best performance with high accuracy and strong ROC-AUC score.

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Google Colab
